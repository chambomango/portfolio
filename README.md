# Ben Chamberlain - Personal Website

**Live Demo:** [benchamberlain.vercel.app](https://benchamberlain.vercel.app/)

## About

I started this portfolio website in **January 2026** to present my skillset and showcase projects I'm working on. I care a lot about staying current with the rapid changes in our field, working with AI coding companions, refining my workflow, and
keeping up with new tools and evolving languages and frameworks.

My goal with these personal projects is to create scalable, accessible, and modern user interfaces with a strong focus on performance and thoughtful user experience.

This site was built with **TypeScript**, **React 19**, and **Next.js**, leveraging:

- **TailwindCSS** for utility-first styling
- Customized **Shadcn UI** components for consistent, accessible design
- React Server Components (RSC) for reduced client-side bundle size
